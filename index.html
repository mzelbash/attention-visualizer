Question: To mask the future, can we just set those scores to 0?

The answer is No.

Attention turns scores into weights with softmax:

wi= esi ∑jesj

  1. Every score is passed through ex before it becomes a weight.
  2. A score of 0 becomes e0 = 1, not 0. So the future token still gets a share of the attention.
  3. To give it exactly 0 weight we need ex = 0, and that only happens when x = −∞.

What the mask uses: every future score is set to −∞ before softmax. In code this is a large negative number such as −1e9, which keeps the math numerically safe and still gives a weight of 0.
